# NPC 小队系统设计

## 背景与范围

玩家与 3 个 NPC 组成 4 人轻锐小队（1 坦 1 奶 2 输出），NPC 补齐玩家没选的职能。NPC 照原版「剧情辅助器」的思路演戏：固定套路出手，伤害由公式算出，处理机制靠副本给的提示。

小队模式按副本开启：副本 YAML 含 `party:` 块才启用；其余副本保持单人规则（玩家倒地即失败，衰弱 / 濒死复活照旧）。

本子项目交付：多人战斗底座、NPC 行为、动态输出、小队 HUD、隐藏测试副本「小队演练」。不处理：零式式的结算顺序与针对性易伤、多坦克换 T 与挑衅、现有副本的小队化。

## 1. 战斗规则

### 阵营

- 每个实体有阵营 `team`：玩家与 NPC 队友属于小队阵营，boss 与小怪属于敌方阵营。
- 同阵营互为队友：可治疗、可上 buff，不可攻击；敌对阵营可攻击，不可治疗。AOE 命中判定、选目标、治疗目标都按阵营判断，不再按实体类型。
- NPC 队友的实体类型仍是 `player`，另有控制者标记区分真人与 NPC。专指真人的逻辑（镜头、屏幕震动、输入、玩家 HUD）按玩家实体 ID 判断。

### 仇恨

每个敌人持有一张仇恨表。

| 来源 | 仇恨 |
|---|---|
| 对该敌人造成伤害 | 实际伤害值（增伤、暴击都计入） |
| 治疗某队员 | 有效治疗 × 1 + 过量治疗 × 1.5，加到仇恨表里含该队员的每个敌人 |
| 坦克职能 | 以上全部 × 10 |

- 敌人的普攻目标与朝向跟随仇恨第一；第一倒地后自然落到第二。
- 进入战斗时，敌人把小队全员以 0 仇恨加入表中。

### 点名

AOE 锚点新增按小队选人的方式：

| 写法 | 规则 |
|---|---|
| `select: each` | 每个存活队员各一个 |
| `select: count, count: N` | 固定 N 个；存活人数不足时随机重复抽人（某人吃两次） |
| `select: role, role: <tank\|healer\|dps>` | 该职能的存活队员；无人时随机抽一名存活队员 |
| `select: enmity, rank: K` | 仇恨第 K 位（死刑 = 1，双死刑 = 1 与 2 各一个） |

### 分摊

- `share: even`：总伤害按命中人数平分。
- `share: { front: R }`（仅直线与扇形，挡刀）：离施法者最近的命中者承担 R，其余 1 − R 由其他命中者平分；只命中一人时该人承担全部。

### 死亡与团灭

- 队员倒地后保留在场上，头顶持续显示空血条，可被复活。战斗继续，全员倒地才判定团灭。
- 玩家倒地后镜头停在原地，屏幕提示「等待队友复活，或按 ESC 重新开始」；暂停菜单可直接重开。
- 玩家职能为治疗时，第一次倒地自动复活（沿用衰弱 / 濒死演出），之后的倒地只能等团灭或重开。

## 2. NPC 行为

### 外观与技能组

- 每个 NPC 借用一个职业的外观（模型、技能图标、技能特效），职业从玩家未选的可玩职业中按职能挑选；显示名为职业名。
- 技能为 NPC 专用的小技能组，无 MP，强力技能有内置冷却：

| 职能 | 技能 |
|---|---|
| 坦克 | 近战 GCD 连段、高伤能力技、强力减伤（内置冷却） |
| 治疗 | 读条输出 GCD、单奶、群奶、HoT 或群减、复活（读条 4s，冷却 8s） |
| 输出 | 近战或远程主输出 GCD、高伤能力技 |

### 伤害结算

- NPC 按 2.5s GCD 出手，能力技穿插在 GCD 之间。
- 出手瞬间结算这一发的伤害：小队总 DPS（见第 3 节）× 该 NPC 职能份额 × 2.5s × 技能权重 × 随机抖动（±10%）。
- 职能份额按 DPS : T : H = 1 : 0.7 : 0.5 归一。技能权重保证一个 GCD 周期内所有出手之和等于一个 GCD 的份额，能力技转好的周期由能力技分走一部分。
- 走位丢掉的 GCD 不补发；boss 血量因此落后，下次重算时动态输出自然上调。
- 仇恨按实际结算的伤害计。

### 决策

每个 NPC 每 0.15s 在逻辑时钟上决策一次，按以下优先级取第一个成立的行动：

| 优先级 | 坦克 | 治疗 | 输出 |
|---|---|---|---|
| 1 | 倒地：不行动 | 倒地：不行动 | 倒地：不行动 |
| 2 | 躲机制 | 躲机制 | 躲机制（打断读条；法系读条过半时有小概率读完再走） |
| 3 | 死刑前开减伤；或自身血量 < 25% 开减伤（共用冷却） | 奶坦克 | 按优先级攻击 |
| 4 | 把 boss 拉到坦克点位并攻击 | 奶团血（≥ 2 人 < 70%：群奶） | 无目标：回待机位 |
| 5 | 无目标：回待机位 | 单奶（某人 < 50%） | |
| 6 | | 复活（坦克 > 玩家 > 其他人） | |
| 7 | | 攻击 / 待机 | |

- 死刑：伤害类型为 `tankbuster` 的技能。坦克 NPC 在其结算前随机 1–3s 尝试开减伤；减伤还在冷却就硬吃。
- 全屏 AOE：无地面预兆（`telegraph: false`）的 AOE。治疗 NPC 在其结算前铺 HoT 或群减。
- 目标选择：在可选中、存活的敌人里取 `priority` 最高者，同优先级取最近者。坦克 NPC 在 boss 可选中时始终打 boss。无可攻击目标时停手回待机位，治疗照常。

### 站位

- 默认队形：坦克 NPC 把 boss 拉到 `tankSpot` 并让 boss 朝向其 `facing`（默认场地中心、朝北），坦克站在 boss 朝向一侧；其余 NPC 在 boss 背侧，近战贴身，远程与治疗离 boss 8–10m。
- 玩家是坦克时，其余 NPC 仍站 boss 背侧，boss 位置由玩家决定。

### 机制处理

- NPC 依据时间轴行动：AOE 从生成起即可被 NPC 读取（不等预兆显示），时间轴机制条目出现即视为已知。反应延迟从该事件起算，随机 0.3–0.9s。
- 躲避：移动到附近、离所有待结算 AOE 边缘 ≥ 1.5m 的安全点，落点带随机偏移。
- 点位：时间轴条目可挂 `npc.spots`（分散、分摊、死刑点）。
  - 最南侧的点留给玩家；NPC 按离自己最近认领其余空点。玩家站进某个 NPC 的点时，该 NPC 改去剩余空点（含留给玩家的点）。
  - NPC 走到点位容错圆内的随机位置；容错默认 1.5m，可按条目或按点位覆盖。
- 失误：每次机制每个 NPC 以 `mistakeRate`（默认 0.03）的概率失误：反应慢半拍，或落点偏到容错的 2–3 倍。

## 3. 动态输出

- 正常玩家 DPS `P`：职业平衡文档的 DPM 基线 ÷ 60，作为可调常量。
- 带 NPC 的全队有效输出按正常 4 人队（1 + 1 + 0.7 + 0.5 = 3.2P）耗时多 30% 计，为 3.2P ÷ 1.3 ≈ 2.46P。
- NPC 小队基准 `B` = 2.46P − 玩家职能权重 × P（输出 1、坦克 0.7、治疗 0.5）。
- 目标时间：默认 = boss 总血量 ÷ 2.46P；`party.targetTime` 可覆盖。
- 每 3s 重算 NPC 小队总 DPS：
  1. 所需 = boss 剩余血量 ÷ 剩余目标时间（剩余时间下限取一个小正数，过时后所需持续上升）；
  2. 差额 = 所需 − 玩家最近 30s 的 DPS；
  3. 夹在 [0.5B, 1.25B]；
  4. 平滑过渡到新值，单次变化有上限。
- DPS 统计：NPC 合并为一行「队友」，玩家单独一行。
- 开发者终端可查看 `P`、`B`、所需、玩家 DPS、NPC 当前输出。

## 4. HUD

- 小队列表（屏幕左侧，玩家排第一）：职业图标、名字、血条、读条、buff；倒地显示空血条与倒地标记。点击或 F1–F4 选中对应队友。
- 场景内队友：头顶显示名字；掉血时显示血条，倒地后持续显示空血条；被选中时脚下显示友方颜色的目标环。
- 选目标：Tab 与攻击技能只在敌人间切换；治疗技能只作用于队友。单体治疗有选中队友时治疗该队友，否则治疗范围内血量最低者。

## 5. 副本配置

```yaml
party:
  targetTime: 360            # 可省略
  mistakeRate: 0.03
  idle: { x: 0, y: 0 }       # 待机位
  tankSpot: { x: 0, y: 0, facing: north }

entities:
  - id: crystal
    priority: 10             # NPC 转火优先级，默认 0

# AOE 锚点与分摊
anchor: { select: each }
anchor: { select: count, count: 4 }
anchor: { select: role, role: healer }
anchor: { select: enmity, rank: 1 }
share: even
share: { front: 0.5 }

# 时间轴条目上的 NPC 点位提示
npc:
  spots: [{ x: -6, y: 6 }, { x: 6, y: 6, tolerance: 0.8 }]
  tolerance: 1.0
```

## 6. 测试副本「小队演练」

隐藏副本，验收内容：

- 普攻与仇恨，含玩家治疗过量刷奶导致 OT；
- 全屏 AOE、死刑、每人一个的分散、平分分摊、挡刀直线；
- 固定 4 个点名，含有人倒地时某人被点两次；
- boss 不可选中、只出小怪的阶段（转火优先级与待机）；
- 软狂暴。

## 7. 测试

- 单元测试：仇恨计算、四种点名、两种分摊、动态输出公式、NPC 决策优先级、死亡与团灭判定。
- 浏览器验收：分别以输出、坦克、治疗打一遍「小队演练」。
