# 朱雀诗魂战（极）

替换 `public/encounters/suzaku-extreme.yaml`。浓缩版约 6～7 分钟，参照原版时间轴（cactbot `ui/raidboss/data/04-sb/trial/suzaku-ex.txt`）。单人化。

## 设计原则

- 每个机制首次出现是教学：读条更长、伤害约为常规的 60%、单独出现。全部机制演示过一遍后开始排列组合（鸳鸯锅穿插强制位移、死刑接前方半场刀再接击退、击退接月环等）。
- 原版"随机"是假随机：每种机制只有少数固定变体，开战时或读条时从预设中随机挑选，玩家可从场上提示读出答案。
- 判定与原版一致：多段伤害只是演出，结算在一帧内完成。

## 职能与数值（仅进阶职业）

- 坦克：战士 10000 / 骑士 10000 / 暗黑骑士 12000；DPS：黑魔 8000 / 诗人 9500 / 武士 11000。
- 可回避机制每下约 3800：DPS 吃两下极危险，三下必死。坦克另叠易伤（每层 +12.5%，90s）；DPS 不叠易伤。
- 全屏 AOE 约 1800。
- 死刑「鬼宿脚」：首次（教学）6000，之后 9000。歼殛战标准是不开减伤打到血皮、不穿杀（零式才不开减伤必死），按战士（10000 血 + 铁壁 40%）定；DPS 可拼刀。

## 复活（练习友好）

副本 YAML `revive: true` 开启，本副本开启；爬塔模式不受影响。

- 死亡时清空所有未标记 `preserveOnDeath` 的状态。死亡 1s 后原地复活：回满 HP、回复 25% MP；Boss 时间轴不暂停。
- 复活同时获得「生还」3s：伤害无效（不防击退），使用任意技能或自动攻击即解除。
- 无衰弱/濒死时死亡 → 复活并获得「衰弱」60s：主属性 -25%（技能伤害与治疗量 -25%）。
- 衰弱期间死亡 → 复活并获得「濒死」60s：主属性 -50%，最大 HP 降为 75%。
- 濒死期间死亡 → 挑战结束（进入原有死亡窗口）。
- 图标：衰弱 015010、濒死 015011、生还 015273（FF14 原版状态）。

## 拼刀（DPS 版鬼宿脚）

通用机制见 `src/game/parry.ts`。死刑读条期间屏幕中央显示光圈（转满 = 死刑落下），DPS 可按一次空格进入拼刀姿态；姿态逐段自然过期并转入下一段（无隐藏宽限，跨帧溢出计入下一段）。伤害类型含 `tankbuster`（死刑）的伤害命中时消耗姿态并按当前阶段结算：

| 阶段 | 持续 | 死刑命中时 |
|---|---|---|
| 完美格挡 | 0.2s | 无伤，「见切」伤害 +20%，10s |
| 格挡 | 0.25s | 无伤 |
| 防御 | 0.45s | 吃 25%（约 1900） |
| 无姿态 | — | 吃全额（约 7500）+ 本副本 `onUnparried`：「破绽」伤害 -20%，10s |

拼刀机制本身不带惩罚，未拼到的后果由每个死刑自行配置。拼刀后紧接前方 180° 半场刀，需绕到背后。

## 场地

- 圆形半径 20。P1 为护栏（wall）。
- 燃烬天火后变环形：中心洞（半径约 8）与外沿均为即死，带破碎演出。
- 四象限地板（中心为原点、正北为 +Y）：东北 黑「り」、东南 黄「な」、西南 青「う」、西北 紫「ろ」；国服俗称"向水十之"。

## 时间轴（浓缩）

**P1**
- 叫唤地狱：全屏。
- 猛进：朱雀飞出场外，从场边某处直线横穿全场（长 55、宽 6），同时玩家头顶分散圈（半径 6）。
- 翼宿击：朝玩家的 90° 扇形。
- 鬼宿脚：死刑（坦克减伤 / DPS 拼刀）→ 前方半场刀。

**小怪战**
- 场地中央 4 具火焰鸟尸体。苏生之羽刷出羽毛，两种布局：正点或斜点。羽毛读条 20s 苏生神通力（半径 9），碰到尸体则复活火焰鸟。
- 玩家头顶苏生之炎，碰到尸体也会复活火焰鸟。
- 复活的火焰鸟 15s 后读条「升天」：全屏重伤，带复活穿透（被它打死直接结束，不进入衰弱/濒死）。
- 羽毛与复活的鸟全部清掉后朱雀回归。

**跳舞机（苏生大火 → 燃烬天火）**
- 朱雀不可选中并飞离。玩家脚下出现光圈，光圈中出现四向箭头，光球飞到的判定瞬间检查：玩家在光圈内且朝向与箭头一致（朝向由移动方向决定）。无按键输入。
- 10 个音符，节奏取原版：3 连每拍约 1.1s，停顿后 7 连，间隔依次为 2.1 / 1.1 / 1.1 / 2.2 / 2.1 / 1.2s。
- 成功：玩家叠 1 层伤害提高（每层 +10%，180s，死亡清除；叠少了 P2 过不了 DPS 检测）。失败：朱雀叠 1 层伤害提高（叠多了朱雀后续攻击可秒人）。
- 燃烬天火读条 7s 全屏，之后场地变环形。

**P2（教学段）**
- 星宿波：全屏。
- 引诱旋律：吸引向中心洞，需站外沿。
- 井宿焰（宽直线，朝玩家）+ 苏生之炎。
- 鬼宿脚 → 半场刀。
- 朱红旋律（鸳鸯锅）：场外东西两侧各一列图标，火焰鸟从南侧顺时针绕场飞，碰到图标则对应象限地板喷火，并把玩家击飞（击飞期间无法移动与施放技能）。8 连炸，序列取自预设（黄色起顺时针 / 青色起对角回文）。首次间隔放慢。
- 拒绝旋律：击退，需站内沿。
- 傀儡旋律：玩家连线某个方向的火球，debuff 到期后朝该方向强制移动 4s。

**P2（组合段）**
- 鸳鸯锅 8 连 × 2，期间穿插傀儡诗强制位移。
- 鬼宿脚 → 半场刀 → 拒绝/引诱。
- 击退接月环。
- 鸳鸯锅 4 连 × 若干，对角型、起点随机，穿插井宿焰 + 苏生之炎。

**狂暴（之之之之）**
- 四块地板全部变成紫色「ろ」，朱雀无限复读全场鸳鸯锅，直到玩家死亡。伤害为特殊伤害（无视无敌、减伤与护盾），狂暴开始后死亡不再复活。

## 引擎积木

1. 职能感知：副本可读玩家职能；技能与效果支持 `when: { role: tank | dps }`。
2. 头顶点名标记：分散、分摊、死刑点名，跟随玩家，到时结算。
3. 场地变形：时间轴动作把圆盘变为环形（中心洞 + 外沿即死），带演出。
4. 具名地板分区：四象限各有名字、颜色与图标，可单独引爆。
5. 演出移动：实体沿路径飞行或冲锋，可飞出场外、从场边出现。
6. 强制移动 debuff：到期朝固定方向强制移动。
7. 拼刀：空格进入逐段过期的拼刀姿态，死刑命中时按阶段结算；未拼到的惩罚由死刑配置。
8. 朝向判定：在指定时刻检查玩家是否站在圈内且朝向与指定方向一致（跳舞机）。

另需：击飞状态（无法移动与施放；空中仍受伤害，仅不会被再次击飞）。机制伤害沿用现有 `attack × potency` 固定数值，不按百分比。

## 分期

1. 积木 1、2、7 + P1 + 小怪战 + 拼刀死刑。
2. 积木 3、5、8 + 跳舞机 + 场地变环形 + 击退/吸引。
3. 积木 4、6 + P2 鸳鸯锅、傀儡旋律、组合段、狂暴。

每期结束：类型检查、定向测试、浏览器实测。

## 验证

- 单测：QTE 判定窗口、跳舞机朝向判定与叠层归属、鸳鸯锅预设序列、职能条件、强制移动方向、环形场地即死判定。
- 浏览器：三种坦克与三种 DPS 各打一遍，确认数值手感（DPS 两下危险、三下死）。

## 练习工具

dev 终端 `seek <秒|检查点>` 跳转时间轴，跳过段落中的显隐、站位、场地变形会被快进补上；检查点：小怪、跳舞机、燃烬天火、p2、鸳鸯锅、傀儡旋律、组合、狂暴。

## 待调优（试玩反馈）

- 整体过难：单人无治疗，P1 已难以通过；坦克同时承受 Boss 与复活火焰鸟的自动攻击时回复跟不上。
- 已知诱因：复活的火焰鸟沿用 Boss 自动攻击技能，且 `BossBehavior` 默认自动攻击距离 15m（远程平 A）。
- Boss 血量 18.5 万（目录 DPS 检测约 535）：跳舞机的伤害提高按层数生效后，正确处理跳舞机的收益很大，在此基础上给吃机制、死亡与叠层不满留余量。
- 坦克补正减半：Boss 自动攻击坦克 900 → 600（DPS 300），易伤每层 25% → 12.5%。
- DPS 站桩也能过（黑魔全程站桩约 3:30 击杀），待观察坦克补正调整后的整体手感。
- 方向（待定）：小怪独立的近战自动攻击与较低伤害；评估 DPS 复活惩罚。
